# 🏀 booking_app

A Flutter-based mobile application for sports facility booking.

## 🚀 Getting Started

This project is a starting point for a Flutter application to manage sports court bookings with features like user registration, real-time availability, and membership benefits.

---

### 🧰 Prerequisites

Before running the app, make sure you have the following installed:

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- Dart SDK (comes with Flutter)
- Android Studio / VS Code with Flutter & Dart plugins
- A connected device or emulator

---

### 🛠️ Setup Instructions

1. **Clone the repository:**

   ```bash
   git clone https://github.com/your-username/booking_app.git
   cd booking_app
   ```

2. **Install dependencies:**

   ```bash
   flutter pub get
   ```

3. **Run the app:**

   ```bash
   flutter run
   ```
